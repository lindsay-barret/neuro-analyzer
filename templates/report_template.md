# Template de rapport — Neuro-Analyzer

Ce fichier sert de référence pour la structure du rapport.
Le rapport est généré programmatiquement par `report_generator.py`.

## Structure attendue

1. Données techniques de l'acquisition
2. Inventaire des séquences
3. Synthèse des observations (agrégation automatique)
4. Cartographie de la malformation (régions anormales/normales/incertaines)
5. Analyse détaillée par plan (axial, coronal, sagittal)
6. Analyse SWI
7. Corrélation avec le dossier clinique
8. Questions pour le neuroradiologue
9. Limitations

## Notes

- Le rapport doit être en français
- Les termes médicaux en anglais sont acceptés (convention internationale)
- Chaque affirmation doit être qualifiée par un niveau de confiance
- Le rapport ne doit JAMAIS poser de diagnostic — il décrit des observations
